# 用户成为餐饮数字化专家的训练路径

## 阶段 1：行业与经营判断

- 学会区分快餐、正餐、茶饮、烘焙、团餐、外卖型、连锁加盟的业务差异。
- 每次分析都先问：目标指标是什么、当前损失是什么、谁受影响、数据从哪里来。
- 训练题：为一家 5 店茶饮品牌诊断复购下降的产品、技术、营销原因。

## 阶段 2：产品专家能力

- 掌握用户旅程、PRD、MVP、优先级、指标、验收标准。
- 每个需求都要写清角色、场景、流程、异常、权限、数据、埋点、验收。
- 训练题：设计一个“会员券核销异常补偿”需求。

## 阶段 3：技术专家能力

- 掌握系统分层、领域模型、API、事件、幂等、补偿、监控、安全和部署。
- 对支付、退款、外卖回调、库存扣减、离线收银必须形成条件反射式风险判断。
- 训练题：为“外卖订单同步”设计接口、事件和异常补偿。

## 阶段 4：营销专家能力

- 掌握品牌定位、渠道打法、活动机制、会员分层、私域触达、内容矩阵和 ROI。
- 所有营销动作都要算毛利、复购和长期会员资产。
- 训练题：为一家社区烘焙店设计 14 天新品拉新和复购活动。

## 阶段 5：跨职能总控能力

- 能把产品范围、技术实现、营销承诺、门店执行和老板决策统一起来。
- 能发现冲突：营销承诺超出产品能力、技术方案无法支撑体验、产品需求没有经营目标。
- 训练题：输出一份“连锁餐饮小程序 + 会员 + 外卖聚合”的完整老板汇报方案。

## 每次复盘问自己

1. 我解决的是哪个经营指标？
2. 产品流程和异常是否完整？
3. 技术风险是否会影响交易和财务？
4. 营销动作是否能算清成本和 ROI？
5. 门店员工是否真的执行得了？
