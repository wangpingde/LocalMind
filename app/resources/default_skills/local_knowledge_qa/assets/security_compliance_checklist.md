# 餐饮系统安全合规清单

## 1. 权限与隔离

- [ ] 租户、品牌、门店、区域、加盟商数据隔离明确。
- [ ] 总部、区域、门店、店长、收银员、财务、供应链权限最小化。
- [ ] 高风险操作需要二次确认、审批或审计。

## 2. 敏感数据

- [ ] 手机号、地址、支付流水、会员消费记录按需脱敏。
- [ ] 储值、积分、优惠券、退款等资金相关数据可追溯。
- [ ] 导出数据有权限控制、水印或操作日志。

## 3. 支付与财务

- [ ] 支付密钥、证书、回调验签和 IP 白名单管理清晰。
- [ ] 支付、退款、对账、日结均有审计记录。
- [ ] 财务报表口径和原始流水可追溯。

## 4. 运维安全

- [ ] 生产访问需要最小权限和操作记录。
- [ ] 配置变更、批量改价、菜单同步有审批和回滚。
- [ ] 备份、日志和监控数据有保留周期。

## 5. AI 与数据使用

- [ ] AI 助手只能访问用户有权访问的数据。
- [ ] 关键经营建议标注数据来源和时间范围。
- [ ] 资金、财务、价格类操作必须人工确认。
