# 餐饮系统稳定性评审清单

## 1. 交易链路

- [ ] 下单、支付、退款、券核销、库存扣减均具备幂等。
- [ ] 支付成功但订单未更新有补偿任务。
- [ ] 外卖平台状态和本地订单状态不一致可对账修复。
- [ ] 打印/KDS 失败有重试和人工补打。

## 2. 弱网与离线

- [ ] POS 弱网时可继续查看菜单和历史订单。
- [ ] 离线订单有明确风险边界、同步状态和冲突处理。
- [ ] 门店局域网设备故障有人工兜底。

## 3. 高峰容量

- [ ] 评估门店午晚高峰、营销活动、外卖爆单流量。
- [ ] 对订单、支付、报表、消息队列有容量指标。
- [ ] 关键接口有限流、降级、缓存或排队策略。

## 4. 可观测性

- [ ] 日志包含 tenant_id、store_id、order_id、payment_id、trace_id。
- [ ] 监控覆盖接口错误率、延迟、队列堆积、支付回调失败、打印失败。
- [ ] 告警有负责人、阈值、升级路径和 Runbook。

## 5. 恢复能力

- [ ] 数据库、对象存储、配置和密钥有备份。
- [ ] 支持代码回滚、配置回滚和数据修复。
- [ ] 有故障演练和复盘机制。
