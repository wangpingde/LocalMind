# 餐饮会员生命周期运营模板

## 1. 分层规则

| 分层 | 识别条件 | 核心目标 | 触达渠道 |
|------|----------|----------|----------|
| 新客 | 首次消费/新入会 | 完成首单体验 | 短信/小程序/企微 |
| 首单未复购 | 首单后未在周期内复购 | 引导第二单 | 券/社群/企微 |
| 活跃会员 | 近期多次消费 | 提升客单与频次 | 会员日/套餐 |
| 高价值会员 | 高客单/高频/储值 | 维护和专属权益 | 专属客服/活动 |
| 沉睡会员 | 长期未消费 | 唤醒或流失确认 | 短信/券/新品 |
