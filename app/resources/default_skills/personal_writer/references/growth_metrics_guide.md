# 餐饮增长指标与 ROI 口径

## 1. 漏斗指标

| 阶段 | 指标 | 口径 |
|------|------|------|
| 曝光 | 曝光量、触达人数 | 渠道展示或消息触达人数 |
| 点击 | 点击率、进店率 | 点击/曝光，进店/曝光 |
| 领取 | 领券率、入会率 | 领取或入会/触达 |
| 转化 | 下单率、到店率、核销率 | 成交或核销/领取 |
| 复购 | 7/14/30 天复购率 | 再次消费人数/首购人数 |
| 裂变 | 分享率、邀请成功率 | 分享或邀请成交/参与人数 |

## 2. 财务指标

- 活动 GMV：活动带来的交易额。
- 实收金额：顾客实际支付金额。
- 优惠成本：商家承担的券、折扣、赠品成本。
- 渠道成本：平台佣金、达人费用、投流费用、短信费用。
- 毛利额：实收金额 - 商品成本 - 优惠成本 - 渠道成本。
- ROI：(活动毛利额 - 活动固定成本) / 活动固定成本。
- 保本订单数：固定成本 / 单笔订单贡献毛利。

## 4. 复盘判断

- 只带来低毛利一次性订单的活动，不应被误判为成功。
- 拉新活动要观察后续复购，不只看首日核销。
- 储值活动要关注未来履约成本和退款风险。
- 外卖平台活动要扣除佣金和平台补贴归属后再算 ROI。
