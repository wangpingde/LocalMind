# 餐饮营销专家手册

## 1. 餐饮营销先判断目标

- 拉新：扩大新客到店/下单，关注获客成本和首单转化。
- 转化：提升曝光后的购买率，关注套餐、价格、评价和行动指令。
- 复购：让老客按消费周期再次购买，关注会员分层和触达节奏。
- 提客单：通过套餐、加购、储值和场景组合提升客单价。
- 清库存：在不伤品牌的前提下处理临期、滞销或季节性商品。
- 品牌：强化品类记忆、招牌产品、商圈影响力和内容资产。

## 2. 渠道打法

- 门店：海报、桌贴、店员话术、试吃、排队区、收银台。
- 外卖平台：店铺装修、菜品图、满减、会员券、评价运营、搜索排名。
- 抖音团购：套餐设计、短视频素材、达人探店、直播核销。
- 小红书：场景种草、拍照点、攻略型笔记、真实体验。
- 私域：企微、社群、小程序、短信、公众号，重点做复购和储值。

## 3. 活动设计原则

- 一个活动只服务一个主要目标。
- 优惠要有门槛、时效、库存和核销路径。
- 员工执行动作必须简单，话术必须可复制。
- 所有活动都要算毛利，不要只看 GMV。
- 复盘必须形成下一次可执行的优化动作。

## 4. 餐饮文案原则

- 具体食材、口味、分量、场景和价格比抽象情绪更有效。
- 每条文案都要有明确行动：领券、下单、到店、入群、储值、分享。
- 平台文案要符合渠道语境：抖音重画面，小红书重体验，社群重信任。
