# 餐饮产品上线验收检查清单

## 1. 功能验收

- [ ] 主流程可从入口完整走到结果反馈。
- [ ] 堂食、外卖、自提、预约、退款等渠道差异已覆盖。
- [ ] 总部、门店、店长、店员、财务、加盟商权限已验证。
- [ ] 菜品、价格、库存、优惠、会员、支付等配置生效规则已验证。

## 2. 异常验收

- [ ] 支付失败、超时、重复回调、金额不一致有处理方案。
- [ ] 退款失败、部分退款、原路退回失败有人工兜底。
- [ ] 外卖取消、骑手异常、平台回调乱序有补偿机制。
- [ ] 打印失败、KDS 失败、弱网/断网有兜底流程。
- [ ] 库存不足、菜品沽清、券锁定超时有提示和恢复方案。

## 3. 数据验收

- [ ] 订单、支付、退款、券核销、库存扣减状态一致。
- [ ] 金额、优惠、佣金、服务费、成本口径可对账。
- [ ] 埋点事件、经营指标和报表口径已验证。
- [ ] 历史配置变更不会污染历史订单快照。

## 4. 上线验收

- [ ] 灰度门店、灰度用户、回滚条件已明确。
- [ ] 监控指标、告警阈值、客服话术、门店培训材料已准备。
- [ ] 上线后观察窗口和复盘负责人已明确。
- [ ] 重大风险已给出业务兜底方案。
