# 餐饮数字化产品专家手册

## 1. 先分业态再做产品

不同餐饮业态的产品重点不同：

- 快餐：高峰期效率、排队、套餐、快速出餐。
- 正餐：桌台、预订、多人点餐、加菜、服务流程、退菜。
- 茶饮/烘焙：规格加料、库存沽清、外卖、自提、会员复购。
- 团餐：批量订餐、结算、发票、企业账户、配送。
- 连锁加盟：总部配置、价格策略、门店权限、督导、加盟数据。

## 2. 餐饮产品的核心对象

品牌、门店、桌台、员工、顾客、会员、菜品、规格、套餐、订单、支付、退款、优惠券、库存、采购、供应商、日结、设备。

## 3. PRD 必须写清楚的地方

- 状态机：订单、支付、退款、出餐、券核销。
- 异常：支付失败、重复回调、库存不足、菜品沽清、外卖取消、打印失败。
- 权限：总部、区域、门店、店长、收银员、后厨、财务。
- 配置：品牌级、门店级、渠道级、时段级、菜品级。
- 指标：交易成功率、出餐时长、翻台率、客单价、复购率、毛利率、活动 ROI。

## 4. 判断优先级

P0：不做就无法交易或会造成财务风险。  
P1：影响门店效率、用户体验或经营数据。  
P2：增强运营能力或提高长期增长。

## 5. 评审问题

1. 这个需求解决哪个经营指标？
2. 是否覆盖堂食、外卖、自提等渠道差异？
3. 异常流程是否比正常流程更完整？
4. 门店弱网/设备故障时怎么兜底？
5. 总部配置与门店个性化如何兼容？
